Why Sonzra

Built for the collection you care about.

Streaming services optimize for their catalogues. Sonzra puts your own music, your own listening history, and your own media server first—without sending it to a third party.

◌

One listening home

Browse music, podcasts, audiobooks, artists, albums, genres, and playlists across Jellyfin and Plex.

⌁

Thoughtful discovery

Saved mixes, radio, favourites, and hidden artists make recommendations feel like yours.

↓

Ready when offline

Download tracks and collections to supported browsers, with artwork and playback preserved locally.

♫

Made to listen

Keep a persistent queue, resume long-form audio, and follow time-synced lyrics from LRC files.

In your library

Designed for the everyday listen.

Use Sonzra as a responsive web app or install it as a PWA. The same player stays with you while you browse.

Install anywhere Docker runs

One container. Your server. Your music.

Persistent storage keeps Sonzra’s databases, encrypted credentials, jobs, and installation secret. Pending database migrations run automatically when the container starts.

docker compose up -d

Requirements

Bring your own library.

  • A reachable Jellyfin or Plex server
  • A modern browser for web playback and downloads
  • Optional .lrc files for synced lyrics
  • Audiobooks and Podcasts Plex libraries for dedicated long-form sections
  • A stable PLEX_CLIENT_ID only when using Plex
